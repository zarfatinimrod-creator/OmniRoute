# Trader - נוהל סשן מסחר

**עיקרון:** Claude מציע ובודק, הקוד מבצע. הקוד (`aitrader/`) מחליט גודל, סיכון ופקודות.
Claude מוסיף שיקול דעת - חדשות, אירועים, סיכונים שהמספרים לא רואים - ויכול **רק להקטין סיכון**.
כסף נייר בלבד. אף פעם לא הזמנה בכסף אמיתי, לא יצירת חשבונות, לא סיסמאות.

## 0. התחלה (כל סשן)

```bash
cd ai-trader && pip install -q -r requirements.txt
git pull --rebase   # state/ הוא הזיכרון - תמיד מהגרסה האחרונה
python3 -m aitrader verify   # שרשרת ההאש של היומן תקינה? אם לא - עצור ודווח
```
קרא: `state/latest.json`, `state/lessons.md` (5 האחרונים), הדוח האחרון ב-`reports/`.

## 1. סשן מחזור (במהלך המסחר)

1. `python3 -m aitrader cycle --dry-run` - ראה פקודות מוצעות, מועמדים, משטר, סטופים.
2. **אם יש כניסות חדשות** (BUY של מניה שלא מוחזקת) - לכל אחת:
   - `python3 -m aitrader context SYMBOL` - מה אמרנו עליה בעבר, האם צדקנו, לקחים.
   - `python3 -m aitrader news SYMBOL` - כותרות אחרונות.
   - שאל: יש אירוע בינארי ב-5 ימים הקרובים (דוחות, FDA, מיזוג, משפט)? הנפקה/דילול? חקירה/הונאה?
     going-concern? שינוי הנחיות חד? אם כן ->
     `python3 -m aitrader veto SYMBOL --reason "..."` או `shrink SYMBOL 0.5 --reason "..."`.
   - אם אין סיבה קונקרטית - **לא מתערבים**. "תחושה" היא לא סיבה. רוב הימים: אפס התערבויות.
3. `python3 -m aitrader cycle` - מבצע (רק כשהשוק פתוח; אחרת נשאר הצעה).
4. commit + push של `state/` ו-`reports/` (הודעת commit: `trader: cycle YYYY-MM-DD HH:MM ET - <מה קרה>`).

## 2. תחזיות של Claude (stock prediction)

כשיש לך דעה מבוססת על מניה (אירוע, חדשות, נתון חלופי) - רשום אותה כדי שתיבדק:
```bash
python3 -m aitrader predict SYMBOL up --horizon 20 --prob 0.58 --note "thesis; invalidation: ..."
```
- `--prob` = ההסתברות שהמניה **תכה את SPY** באופק. 0.50 = אין דעה (אז אל תרשום). מעל 0.65 רק עם
  ראיה חזקה - מודלי שפה נוטים לביטחון יתר; כרטיס הציונים (Brier) יראה את זה.
- כל תחזית: תזה ב-1-2 משפטים + תנאי ביטול (מה יוכיח שטעיתי).
- תחזיות של Claude נבדקות **רק קדימה**. אסור "לבדוק" אותן על היסטוריה - המודל זוכר את העבר.

## 3. סשן אחרי הסגירה (למידה)

1. `python3 -m aitrader cycle` (סימון סוף-יום, ריבית מזומן, תחזיות שהבשילו נבדקות, משקלות מתעדכנים).
2. `python3 -m aitrader scorecard` - אחוז פגיעה לפי מקור (quant / claude / insider_cluster / congress_buy)
   ואופק. **השווה לבסיס:** קריאות מול SPY - 50% זה מטבע. Brier 0.25 = מטבע.
3. לכל תחזית שהבשילה היום וטעתה בגדול (|excess| > 5%): למה? הנתונים היו שם? הקוד טעה או מזל?
4. כתוב לקח ב-`state/lessons.md` רק אם יש ראיה. פורמט שורה:
   `- YYYY-MM-DD | <תצפית> | ראיה: <מספרים + קובץ> | ביטחון: נמוך/בינוני/גבוה | מה ישנה את דעתי: <...>`
5. לקח משנה התנהגות רק אחרי שאושר בנתונים (30+ מקרים מדורגים, |t|>2) ועבר את מכונת הזמן +
   quant-critic. עד אז הוא רק נרשם.
6. לוג סשן ב-`logs/` עם 8 הכותרות.

## 4. סקירה שבועית (שבת)

1. `python3 -m aitrader backtest --start 2018-01-01 --sweep` (מכונת הזמן; רגישות, לא שורה אחת).
2. רעיון שיפור אחד לשבוע (מחקר ברשת עם `agents/web-researcher.md`): אות חדש, פרמטר, מקור נתונים.
3. בדיקה לפני/אחרי במכונת הזמן; `agents/quant-critic.md` נותן PASS/HOLD. רק PASS נכנס.
4. דוח שבועי לנמרוד: תשואה מול SPY ושווה-משקל, מה למדנו, מה שונה, מה הבא.

## 5. מתי להתריע לנמרוד (ומתי לא)

התראה (push) **רק** כש: בוצעו פקודות; סטופ הופעל; שינוי משטר שוק; ירידה מהשיא עברה -10%;
כשל טכני שעוצר את הבוט; או החלטה שרק הוא יכול לקבל. לא על שגרה.

פורמט: עברית קצרה, טיקרים באנגלית, מספרים מדויקים, בלי סופרלטיבים. שאלה - אחת בהודעה, עם
אפשרויות א/ב/ג והמלצה. תמיד: "כסף נייר".
